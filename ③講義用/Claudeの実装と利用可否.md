# Claudeの提供形態とライセンス

## 実装サービス別の利用可否

| 機能 | WEB: Claude | WEB: Claude Code | desktopアプリ: Claude | desktopアプリ: Claude Code | Claude for VSCode: Claude Code | Claude CLI: Claude Code |
|---|---|---|---|---|---|---|
| CHAT | 〇 | 〇 | 〇 | 〇 | 〇 | 〇 |
| Cowork ※1 | 〇 | － | 〇 | － | － | － |
| Code | ✕ | 〇 | ✕ | 〇 | 〇 | 〇 |

※1 Claude Codeにはローカルファイル操作やスケジュール実行など、Coworkと似た機能があるが、Coworkとは別の機能であり、Cowork自体はClaude Codeには実装されていない

## ライセンス別の利用可否

| 機能 | Free | Pro | Max | Ultra | Team | Enterprise |
|---|---|---|---|---|---|---|
| CHAT | 〇 | 〇 | 〇 | 〇 | 〇 | 〇 |
| Cowork ※3 | ✕ | 〇 | 〇 | 〇 | 〇（ベータ版） | 〇（オーナー判断） |
| Code | ✕ ※2 | 〇 | 〇 | 〇 | 〇 | 〇 |

※2 Freeでも、Consoleアカウント（API課金）を使えば利用可能（サブスクリプションに含まれていないという意味で'✕'）

※3 ベータ版・オーナー判断はWeb・モバイルでの条件。デスクトップアプリは全有料プランで利用可能

Free版：同じアカウントなら、デスクトップで始めた会話やプロジェクト（添付ファイル含む）を、claude.aiやスマホから続けられる
