カレントフォルダにある input.png を読み込んでください。これは手描きのラフなロゴのスケッチです。

このスケッチを、モダンで「可愛い」ロゴとして描き直し、output.svg として保存してください。色を変えるだけではなく、図柄そのものを可愛く作り直してください。

可愛くするためのデザイン方針:
- スケッチの題材(動物やキャラクターなど)と、表情の特徴(むすっとした顔、涙、頬のしるしなど)は残すこと。
- 頭身を低くし、丸みのあるやさしいシルエットにすること。耳や角などの尖った部分も、先端を丸くすること。
- 目は大きくして、ハイライト(白い光)を入れ、うるっとした印象にすること。
- 頬に、ほんのり色の付いたチークを入れること。
- 口やひげなどの細かいパーツは、太めの丸い線でシンプルにすること。
- 配色は、やわらかいパステル調を基本にすること。
- ごく控えめな影やグラデーションで、ふっくらとした立体感を出すこと。
- 全体として、スタンプやアプリのアイコンに使えるような、親しみやすいデザインにすること。

技術的な条件:
- 1つで完結したSVGにすること。viewBox="0 0 800 800" とし、外部リソースや埋め込みのラスター画像は使わないこと。
- 背景は透明にすること。
- output.svg 以外のファイルは作らないこと。

作業が終わったら「完了」とだけ返答してください。
